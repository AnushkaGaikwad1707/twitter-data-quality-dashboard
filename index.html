CRITICAL SEVERITY Problem #1 | Dimension: Semantic Quality

Synthetic Text Indicators & Nonsensical Language

97.9% of tweets (1,958 / 2,000) contain newline characters. Text consists of unnatural word salad (e.g. "Skin baby bar. Unit anyone stay quickly beautiful manage."), lacking hashtags, handles, or standard tweet syntax.

Affected Records
1,958 (97.9%)
Analytical Impact: Models trained on synthetic text will fail entirely when deployed on real-world Twitter data.
Recommended Action: Filter out algorithmically generated text using perplexity screening or replace dataset with natural Twitter firehose samples.
CRITICAL SEVERITY Problem #2 | Dimension: Analytical Reliability

Weak Text–Label Alignment (High Polarity Mismatch)

Lexical polarity screening revealed only 16.56% agreement between tweet text sentiment and assigned labels among 1,347 non-neutral records. 83.44% exhibit sentiment label divergence.

Polarity Discrepancy
83.44% (1,124 rec)
Analytical Impact: Supervised classification models (BERT, VADER, RoBERTa) experience gradient corruption and poor generalisation.
Recommended Action: Re-annotate labels using multi-annotator consensus or zero-shot LLM evaluation against a gold standard.
CRITICAL SEVERITY Problem #3 | Dimension: Consistency

Tweet–Metadata Inconsistency (Complete Contradiction)

Exactly 0 out of 2,000 tweets contain any '#' or '@' symbol in raw text. However, metadata columns report 1,641 records with hashtags and 1,484 with mentions.

Contradiction Rate
100% (2,000 rec)
Analytical Impact: Feature engineering based on entity extraction creates false correlation signals and pipeline failure.
Recommended Action: Re-extract metadata directly from tweet text using regex parsing or drop corrupted metadata fields.
CRITICAL SEVERITY Problem #4 | Dimension: Completeness

Missing Mentions Metadata (>1 in 4 Records)

516 records (25.80%) lack mention metadata entries, preventing social interaction mapping and user-network graph construction.

Missing Mentions
516 (25.80%)
Analytical Impact: Node-edge social network graphs will be fragmented with significant edge deletion.
Recommended Action: Impute or re-mine mention tags if network centrality is part of downstream workflow.

Data Remediation & Mitigation Roadmap

PHASE 1
Regex & Syntax Cleaning

Strip newline characters (\n), parse timestamp dtypes to datetime64[ns], re-extract text entity tags.

PHASE 2
Synthetic Language Filter

Run perplexity scoring and n-gram language models to isolate and discard non-human text records.

PHASE 3
Label Re-Annotation

Re-annotate text sentiment using zero-shot LLM classifiers or crowd-sourced gold standards.

PHASE 4
Validation Audit

Re-verify text-label alignment (>75% threshold required) before deploying to production training pipelines.
